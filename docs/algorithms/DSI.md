# DSI Python 移植说明

本项目中的 `sade_benchmark/algorithms/dsi/` 以本地 `code_local/DSI/DSI_ECOP.m` 为基准，目标是复现实验逻辑，而不是改良算法。算法名称、数据流和关键判断均可对应回 MATLAB 文件。

## 默认论文参数

默认值及参数合法性检查定义在 `sade_benchmark/algorithms/dsi/config.py`。

```text
population_size = 30
max_evaluations = 300
wmax = 10
runs = 30
```

CEC2006 使用各问题固定维度；CEC2010 和 CEC2017 的 10D、30D 属于本地论文程序覆盖范围。框架也允许 DSI 运行 CEC2017 50D、100D，但这些属于扩展实验。

## 单次运行流程

1. 在完整变量范围生成五组 Latin hypercube 设计，保留最小点间距离最大的一组，对应 MATLAB `lhsdesign` 的默认 `maximin` 和五次迭代。
2. 真实评价初始种群，按总约束违反度优先、目标值次优排序，建立大小为 `population_size` 的 `A1`。
3. 对真实评价档案按六位小数去重，建立目标与所有约束的联合 cubic RBF；联合模型仅用于重复候选发生时的不确定度选择。
4. 根据 `Obj_rm` 和 `D_rm` 分别删除目标模型、约束模型的部分训练数据，再建立独立的目标和约束 cubic RBF。
5. 调用嵌入式 C2oDE，在代理模型上执行 `wmax` 代：
   - 每个父代产生三个候选；
   - 三个候选之间按可行性规则预选；
   - 使用动态 epsilon 规则更新代理种群；
   - 同时保存中点代 `Half` 与最终代种群。
6. 最终种群产生第一个真实评价候选，中点种群产生第二个候选。若第一个候选与历史样本距离不超过 `1e-11`，则改为从 `Half` 中选择 RBF 不确定度最大的候选。
7. 真实评价一个或两个候选，更新 `A1` 与完整训练档案。
8. 根据最终代候选和中点候选的真实表现，将 `wmax` 减半或加倍，并限制到 `[5, 80]`。
9. 当代理预测的可行性与真实可行性不一致时，利用 RBF 径向项贡献定位训练节点，更新目标/约束数据删除集合。
10. 达到真实评价预算后，按可行解优先、可行解中目标最小返回结果。

## 与 MATLAB 参考实现的边界

- NumPy 与 MATLAB 的随机数发生器不同，因此相同数字 seed 不要求逐点轨迹完全相同；复现比较应使用 30 次运行的均值、标准差、中位数和可行率。
- RBF 线性系统采用最小二乘求解，使重复点或高维欠定系统不会中断运行；公式仍是 cubic RBF 加线性多项式尾项。
- 最后一批会按剩余预算缩短；完全相同的两个候选只真实评价一次。因此 Python 结果严格不超过 `max_evaluations`。
- 代码没有加入额外启发式改良。后续若修改 DSI，应使用新的算法名称（例如 `dsi_modified`），避免污染复现基线。
