# SADE V2.10：双尺度局部候选

V2.10从V2.9分支，只修改局部候选池的生成方式。代理模型、原始CV/P90阶段
切换、连续CEI、两点批次、停滞边界点、真实排序和种群更新均保持不变。

## 唯一算法改动

每代局部候选总数仍为`batch_size * population_size`，默认是60个，并按固定
比例平分：

1. 30个粗尺度候选完全保留原局部搜索：半径从0.30线性衰减到0.10，改动
   `max(1, floor(radius * D))`个变量；
2. 30个细尺度候选使用
   `max(0.01, 0.1 * coarse_radius)`，且只改动一个变量。

两类候选合并后仍由同一套V2.9采集函数竞争，不预留真实评价名额，也不赋予
细尺度额外优先级。该版本没有新增可调超参数，50/50拆分、0.1半径比例、0.01
半径下限和单变量扰动均是本次消融的固定定义。

保存候选池时，粗细局部池分别标记为`local_search_coarse`和
`local_search_fine`；真实评价轨迹还会记录所选局部点的尺度、半径和改动变量
数量，便于判断细尺度候选是否实际产生贡献。

## 开发实验结论

该版本保留为可复现的失败消融，不作为当前主线。CEC2017 C22-30D在5个种子
下仍为0/5可行；细尺度点虽然比粗尺度点更频繁被选中和降低CV，但5次运行的
最终最低违反度均来自全局DE，且最终违反度均值和中位数均劣于V2.9。

C05-10D有所改善，但C05-30D的5次均值由V2.9的约6.73e3退化到约1.30e4。
因此证据不支持继续通过固定双尺度比例调节局部半径。后续若改进候选生成，
应优先研究局部点加入真实种群后对DE种群收缩和搜索方向的影响。

进一步按变量范围归一化后统计真实种群的平均两两距离：C22-30D后半程均值从
V2.9的约2.35e-2降到V2.10的约1.39e-2，下降约41%；最终种群距离均值下降
约32%。这与“细尺度点频繁以小幅CV优势进入种群，导致DE差分向量过早收缩”
的解释一致。
