# SADE V2.7：动态两点批次

V2.7保留V2.6的两点批次和V2.5的全部采集函数，只把第二个槽位从固定局部点
改成由真实停滞状态控制的局部点或边界探索点。

## 批次规则

每个完整批次的第一个点始终是V2.5的全局点1。第二个点通常是V2.5的局部
点1；当连续`boundary_stagnation_batches`个完整批次没有真实改善，第二个点
切换为边界探索点。默认阈值为3批，即6次真实评价。

真实改善采用与真实种群一致的可行优先比较：

1. 尚无可行解时，找到可行解或者固定尺度CV下降均视为改善；
2. 已有可行解时，新的真实可行目标低于批次开始前的最优目标才视为改善。

边界批结束后，无论该批是否立即改善，停滞计数都清零。只有再次连续达到默认
3批无真实改善，才会重新触发边界探索；任意批次发生真实改善后也会清零。
因此在持续停滞时，第二槽位按“三个局部点、一个边界点”循环，边界占比上限
约为25%，不会隔批触发。

边界点仍使用原规则：在低预测CV的前20%候选中选择目标RBF几何不确定性最大
的点。P90约束校准、连续CEI回退、目标排序、候选生成、种群更新和局部半径均
保持不变。
