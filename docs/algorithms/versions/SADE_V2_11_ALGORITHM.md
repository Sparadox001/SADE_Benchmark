# SADE V2.11：可行性阶段最近邻竞争淘汰

V2.11从V2.7直接分支，只修改真实评价后的DE父代种群更新。代理模型、P90
约束校准、连续CEI回退、两点批次、停滞触发边界探索、候选生成和局部搜索
全部保持V2.7不变。

## 唯一算法改动

在完整真实评价档案中尚未出现可行解时，每个新评价点只与归一化设计空间中
距离最近的当前父代竞争：

\[
i^*=\arg\min_i\sqrt{\frac{1}{D}\sum_{j=1}^{D}
\left(\frac{x_j-p_{ij}}{u_j-l_j}\right)^2}.
\]

竞争仍使用V2.7的固定尺度可行优先规则。该阶段实际上全部个体均不可行，
因此首先比较固定尺度标准化CV，CV相同时再比较目标值。新批次中的点先按同一
真实规则从优到劣处理，以避免全局点或局部点因槽位顺序获得固定优先权。

所有新评价点无论是否进入父代种群，始终进入完整评价档案，继续用于RBF训练
和最终结果选择。最近邻竞争只影响下一轮DE使用的30个父代。

一旦历史档案或当前批次中出现至少一个真实可行点，当批种群更新立即恢复
V2.7原有的全局截断：从当前父代与新点的并集中，按可行优先、可行目标、固定
尺度CV选出前`population_size`个个体。之后不会切回最近邻竞争。

## 诊断字段

`history.csv`新增：

- `population_survival`：`initial_population`、
  `nearest_neighbor_infeasible`或`global_feasible_first`；
- `nearest_candidates_processed`：该批参与最近邻竞争的新点数；
- `nearest_replacements`：该批实际替换最近邻父代的新点数。

V2.11不增加超参数。它用于检验V2.7在C22首次可行前因全局截断造成多区域
搜索能力过快消失的假设，不用于同时修复C05的代理选点误差。

## 开发实验结论

该版本保留为可复现的失败消融，不作为当前主线。CEC2017 C22在10D和30D下
各运行5个种子、每次300 FEs：V2.11在10D由V2.7的4/5可行退化为0/5；30D
仍为0/5可行，最终原始违反度均值由V2.7的约3.41e3恶化为约2.15e4。

最近邻竞争确实阻止了种群收缩，但明显过度：10D和30D最终归一化平均种群
距离的中位数仍分别保留初始值的约94.3%和93.7%，而V2.7仅保留约1.3%和
2.4%。每次运行仍有约一半新点替换最近邻，说明种群不是完全冻结，而是在多个
初始邻域内分别改进，无法形成足够强的全局CV下降方向。

实验支持“V2.7全局截断过强”和“V2.11纯最近邻竞争过弱”同时成立。后续应在
同一批次内保留一个全局质量竞争槽位和一个邻域竞争槽位，而不是继续调节最近邻
距离或增加新的阈值。
