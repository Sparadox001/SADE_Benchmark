# SADE V2.9：分阶段约束采集

V2.9从V2.7直接分支，只修改候选点的约束违反度排序方式，不包含V2.8的
5近邻目标重排。

## 唯一算法改动

- 在真实评价档案中尚未出现可行解时，候选点按约束RBF直接预测值计算固定尺度
  CV，并优先选择原始预测CV较小的点；此时不把在线P90单侧预测误差加到约束
  预测值上。
- 一旦已有至少一个真实可行解，恢复V2.7原有的P90稳健约束判断、鲁棒可行集、
  连续CEI回退和目标阶段排序。

约束尺度仍是初始30个真实样本的每个约束绝对值P90，并在整次运行中固定。
在线P90误差校准本身也始终继续更新；V2.9只是让它不参与首次找到可行解之前
的候选CV排序。

## 保持不变的部分

DE候选生成、局部搜索、两点批次、连续3批停滞触发边界探索、真实个体的可行
优先比较、种群淘汰和局部半径均与V2.7相同。V2.9没有增加超参数，便于将效果
归因于这一处改动。
