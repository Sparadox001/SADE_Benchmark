# SADE V2.6：两点批次消融

V2.6 是针对V2.5三个昂贵采样槽位效果统计设计的单因素消融版本。V2.5中
固定的第二个全局边界探索点直接改善率很低，因此V2.6将默认批次从3改为2。

每个完整批次只保留：

1. 一个全局点，使用V2.5全局点1的规则；
2. 一个局部点，使用V2.5局部点1的规则。

第二个全局边界探索点不再出现。候选生成、真实种群排序、P90约束校准、硬
可行集阈值、连续CEI回退、最小预测目标规则和局部搜索半径均保持V2.5不变。

在300 FEs和30个初始样本下，V2.5的3点批次执行90轮代理更新；V2.6的2点
批次执行135轮代理更新。真实评价预算仍然都是300，变化仅在每次代理更新之间
提交的昂贵样本数量。

V2.6的Python配置默认`batch_size=2`。为保留实验框架的通用可配置性，该字段
仍可由JSON或命令行覆盖；正式V2.6消融应保持其值为2，否则不再对应上述实验。
