# SADE V2.3

V2.3完整继承V2.2的真实个体排序、DE引导、局部搜索中心、两阶段三个采样角色、
目标标准化EI和固定初始约束尺度。唯一的算法策略变化，是用真实的代理外推误差
校准候选点的约束判断。

## 在线误差样本

每个RBF选择的点在昂贵评价前已经保存逐约束预测值。完成真实评价后，对约束
`j`记录单侧标准化误差：

```text
r_ij = max((g_j(x_i) - ghat_j(x_i)) / s_j, 0)
```

这里只记录低估真实约束的部分，因为它会造成“预测可行、实际不可行”。RBF训练
点上的插值残差不参与校准。默认累计至少12个真实外推误差后启用校准，并仅使用
最近30个误差样本。

## 保守约束和稳健CV

对每个约束取近期单侧误差的90%分位数`q_j`。候选点的保守标准化约束为：

```text
u_j(x) = (ghat_j(x) - tolerance) / s_j + kappa * q_j
```

默认安全系数`kappa=1`。只有所有`u_j(x)<=0`时才属于可靠预测可行点；稳健违反
度为：

```text
robust_CV(x) = sum_j max(u_j(x), 0)
```

V2.3用可靠预测可行集合执行目标阶段EI，用稳健CV执行可行性阶段、边界候选短名单
和无可靠可行候选时的回退。原始预测CV与预测可行标志仍然保存，便于和保守版本
逐点比较。

## 本版本刻意不改的部分

- 每批仍为2个全局点和1个局部点；
- 第二个全局点仍承担边界/不确定性探索；
- EI、几何不确定度和RBF求解方式不变；
- 局部搜索半径与扰动维数不变。

这样本轮实验可以单独判断约束误差校准是否降低假可行率。后续是否加入自适应
第三点或RBF条件数正则化，由V2.3的结果决定。
