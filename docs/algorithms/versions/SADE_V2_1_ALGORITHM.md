# SADE V2.1

`sade_v2` 是独立实验算法，原 `sade` 保持不变。V2.1 只支持单目标最小化、
多个不等式约束 `g_j(x) <= tolerance`。

## 保留的 SADE 部分

- 与 Python DSI 完全相同的 30 点全域 best-of-five maximin Latin hypercube 初始设计；
- 原 SADE 的 10 种 DE 候选生成策略及 `F/CR` 随机机制；
- 全局候选池与连续局部搜索候选池；
- 局部半径从 0.30 线性衰减到 0.10；
- 当前旧版 adaptive penalty fitness 仅用于 DE 引导和种群淘汰；
- 淘汰仍按 penalty 主键、legacy fitness 次键。

legacy fitness 不再是 RBF 的训练目标，也不参与 EI 或昂贵评价点的选择。

## 代理模型

默认从第 30 个有效样本起，每一代拟合两个模型；启用阈值由
`surrogate_min_samples` 控制。同时，带线性尾的 cubic RBF 要求至少有
`D+1` 个唯一训练点，所以实际门槛为
`max(surrogate_min_samples, D+1)`：

1. 一个标量目标 RBF，训练全部有限目标值；
2. 一个多输出约束 RBF，一次预测全部约束，但各输出独立归一化。

两个模型使用固定问题边界把输入映射到 `[-1, 1]`，核函数为 cubic `r^3`，
带线性多项式尾、`1e-10` 正则项，并由 `lstsq(rcond=1e-12)` 求解。
目标 EI 的均值、当前最优可行目标与几何不确定性全部在目标标准化空间计算，
因此不会因目标值简单放大或平移而改变 EI 排名。

## 固定约束尺度

约束尺度使用整个初始种群计算一次，随后不再变化。默认种群为 30 点；若调整
`population_size`，尺度样本数随初始种群一起变化。对约束 `j`：

```text
v_ij = max(g_ij - tolerance, 0)
存在正违反时：s_j = P90({v_ij | v_ij > 0})
没有正违反时：s_j = P90(|g_ij - tolerance|)
s_j = max(s_j, 1e-12)
```

不同候选的预测总违反度统一为
`sum_j max(g_hat_j - tolerance, 0) / s_j`，因此可跨个体比较。

## 两阶段采样

阶段只由真实评价档案决定，代理预测不会触发阶段切换。默认 `batch_size=3`，
全局/局部配额为 2/1。

尚未发现真实可行解时：

1. 全局池：预测归一化总违反度最小；
2. 全局池：先取预测违反度最低的 20%（保留分位点处全部并列候选），再选
   RBF 几何不确定性最大者；
3. 局部池：预测归一化总违反度最小。

发现真实可行解后：

1. 全局池：预测可行点中目标 EI 最大；
2. 全局池：最低预测违反度 20% 中不确定性最大，分位点并列候选全部保留，
   允许预测不可行；
3. 局部池：预测可行点中目标 EI 最大。

若某个 EI 池没有预测可行点，该位置回退到预测违反度最小点。每选出一点后，
下一位置的距离过滤会同时避开真实档案和本批次已选点。极端候选不足时沿用旧版
补足机制，以保证严格用满评价预算。

## 记录

`evaluations.csv.gz` 对每个 V2.1 真实评价点记录阶段、采样角色、预测目标、
逐约束预测、预测归一化总违反度、预测可行性、目标 EI 和代理不确定性。
`history.csv` 记录阶段、RBF 是否启用、训练样本数及固定约束尺度。开启
`--save-candidate-pools` 后，候选池的同类诊断保存于 `candidate_pools.npz`。
