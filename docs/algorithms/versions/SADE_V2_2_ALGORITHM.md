# SADE V2.2

V2.2 保留 V2.1 的 maximin LHS、固定约束尺度、目标/约束 RBF、标准化空间
EI、两阶段 2-global/1-local 采样和距离过滤，只改造真实种群的比较与引导。

## 统一的真实个体比较规则

对真实评价点计算固定尺度总违反度：

```text
CV(x) = sum_j max(g_j(x) - tolerance, 0) / s_j
```

其中 `s_j` 仍由整个初始种群的正违反值 P90 确定，无正违反时回退到绝对值
P90，之后固定。所有真实个体统一按以下规则排序：

1. 可行个体优先于不可行个体；
2. 可行个体按真实目标值从小到大；
3. 不可行个体按固定尺度 CV 从小到大；
4. 不可行个体 CV 并列时按目标值从小到大。

## 使用同一排序的组件

- 种群 survivor selection；
- DE 的 `fbest` 与 `gbest`；
- DE 的 top-p `pbest` 候选集；
- 尚无可行解时的局部搜索中心候选集。

存在真实可行解后，局部搜索中心直接使用当前种群中目标最好的可行个体；尚无
可行解时，从统一排序前 `p_best_fraction` 中随机选中心。原 SADE 每10代随机
选择局部中心的规则不再使用。

因此 V2.2 中代理采样和真实种群演化使用同一个固定尺度约束含义，不再同时混用
adaptive penalty、违反约束数量和固定尺度 CV。RBF采集函数本身暂不改变，便于
单独判断这一项改造的效果。

最终结果选择也使用这套固定尺度规则。候选不足时，从原候选池或变量域补充的
点仍须通过相对于完整评价档案和本批已选点的归一化距离阈值，不再只排除完全
重复的向量。
