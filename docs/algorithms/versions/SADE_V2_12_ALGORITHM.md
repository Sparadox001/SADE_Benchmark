# SADE V2.12：可行性阶段混合淘汰

V2.12从V2.7直接分支，只修改真实评价后的DE父代种群更新。候选生成、代理
模型、采集函数、动态两点批次和局部搜索全部保持V2.7不变，也不增加超参数。

## 唯一算法改动

在完整真实评价档案中尚未出现可行解时，保留V2.7两个采样槽位的原始顺序：

1. 第一个全局点与当前父代合并，使用V2.7固定尺度可行优先规则做一次全局
   截断；
2. 第二个局部点或边界探索点只与归一化设计空间中距离最近的父代竞争，竞争
   仍使用相同的固定尺度可行优先规则。

若最后一批只有一个点，该点是全局槽位，只执行全局截断。若当前批首次产生
真实可行点，则该批立即整体恢复V2.7全局可行优先截断；之后不会切回混合淘汰。

所有真实评价点无论是否进入父代，都保留在完整档案中参与RBF训练和最终结果
选择。混合淘汰只改变下一批DE使用的30个父代。

## 诊断字段

`history.csv`新增：

- `population_survival`：`initial_population`、`hybrid_infeasible`或
  `global_feasible_first`；
- `global_candidates_processed`和`global_candidates_admitted`；
- `nearest_candidates_processed`和`nearest_replacements`。

## 开发实验结论

该版本保留为可复现的诊断消融，暂不替代V2.7。CEC2017 C22在10D和30D下
各运行5个相同种子、每次300 FEs：V2.12在10D获得2/5可行，低于V2.7的
4/5但明显好于V2.11的0/5；30D三个版本均为0/5可行。V2.12在30D的最终
原始违反度中位数为约2.62e3，略好于V2.7的约2.91e3，但均值约3.78e3，
略差于V2.7的约3.41e3；按相同种子比较，V2.12仅在seed 4和5上优于V2.7。

V2.12解决了V2.11过度保留初始邻域的问题，却没有稳定改善V2.7。不可行阶段
每次运行的全局槽位有127--135次进入父代，第二槽位只有约三至五成发生最近邻
替换。最终归一化平均种群距离相对初始值的中位数在10D约1.31%，与V2.7的
约1.3%几乎相同；30D约4.26%，虽高于V2.7的约2.4%，仍然发生强烈收缩。

因此单独把第二槽位改成最近邻竞争不够。每批一个几乎总能进入父代的全局CV
点，已经足以在135批内持续替换整个种群，使搜索重新沿单一CV下降方向收缩。
后续若继续研究淘汰，应直接控制全局替换压力或保留明确的区域配额，而不是只
调整第二槽位。
