# SADE V2.5：鲁棒可行集内最小预测目标

V2.5 是针对 V2.4 候选回放结果设计的单因素消融版本。候选生成、真实个体
比较、约束尺度、P90 约束校准、连续可行性权重、局部搜索和批量分配均保持
V2.4不变，只修改正常目标阶段的开发点排序。

## 目标阶段

对每个全局或局部候选池，先计算V2.4的P90鲁棒可行标记。如果鲁棒可行
候选不少于候选池的5%，V2.5选择

\[
x^*=\arg\min_{x\in\mathcal F_{\mathrm{P90}}}\widehat f(x).
\]

此时不再使用目标EI，几何不确定性仅在预测目标完全相同时作为偏向低不确定性
的确定性次级排序。

如果鲁棒可行候选少于5%，仍使用V2.4的连续CEI回退：

\[
\operatorname{CEI}(x)=\operatorname{EI}(x)
\frac{P_f(x)}{1+\operatorname{ECV}(x)}.
\]

保留该回退是为了把本版实验严格限制为“最大EI改成最小预测目标”这一项变化。

## batch size为3时

在已经存在真实可行解时：

1. 第一个全局点：正常情况下为全局鲁棒可行候选中的最小预测目标；候选不足时为全局连续CEI。
2. 第二个全局点：仍为低预测CV候选中的最大几何不确定性，即V2.4的边界探索点。
3. 一个局部点：正常情况下为局部鲁棒可行候选中的最小预测目标；候选不足时为局部连续CEI。

尚未找到真实可行解时，三个点的选择与V2.4完全相同。
